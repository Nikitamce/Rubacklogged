# Rubacklogged

Независимое Chrome-расширение для Backloggd: русский перевод интерфейса и функции Backloggd Plus — данные Steam, оценки, HLTB, ProtonDB, галереи, мини-профили и экспорт.

Проект не связан с Backloggd.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите каталог проекта.
4. Откройте `https://backloggd.com`. Для русского языка браузера перевод включается автоматически; язык можно сменить в шапке сайта или во всплывающем окне расширения.

Готовый userscript Plus находится в `plus/backloggd-plus.user.js`.

## Возможности

- Перевод целых строк с защитой названий игр, никнеймов, рецензий и других пользовательских данных.
- Поддержка Turbo-навигации, синхронизация языка между вкладками.
- Цены, скидки, отзывы и статус Owned/Wishlist Steam; Steam Deck и ProtonDB.
- OpenCritic, Metacritic, HowLongToBeat, GameStatus и настраиваемые быстрые ссылки.
- Галерея, похожие игры, мини-профили, графики и экспорт игры.
- Настройка видимости блоков главной страницы для ленты и гостевой версии.
- Ускоренный перевод рецензий: кэш извлечения текста, очередь из трёх карточек, backoff ошибок и POST для длинных текстов.
- Экспорт загруженных карточек текущей страницы в JSON при включённом «Show export».
- Импорт и экспорт настроек Plus без API-ключа.
- Журнал сетевых запросов в режиме Debug.

## Приватность и разрешения

Расширение обращается только к перечисленным в манифесте сервисам. Запросы имеют таймаут и ограничение размера ответа. Ключ RapidAPI хранится в `chrome.storage.local`, не экспортируется и не записывается в `localStorage` сайта.

При ручном или автоматическом переводе рецензий и описаний их текст отправляется в Google Translate. Steam Owned/Wishlist использует текущую браузерную сессию Steam. Подробности: [PRIVACY.md](PRIVACY.md).

## Разработка

Требуется Node.js 22 для сборки Plus.

```bash
npm test
npm --prefix plus ci
npm run test:all
npm run build
npm --prefix plus run verify:artifacts
```

`locales/ru.js` — единственный источник русского словаря. Сборка автоматически синхронизирует `plus/src/i18n/site/ru.json`, `plus/backloggd-plus.user.js` и `lib/plus-bundle.js`. Собранные файлы не редактируются вручную.

Дополнительные сведения: [AI-GUIDE.md](AI-GUIDE.md), [CHANGELOG.md](CHANGELOG.md) и документация в `plus/`.
