# Mixed Edition

Текущий репозиторий объединяет русификатор Backloggd и Backloggd Plus. Актуальные инструкции по установке, приватности, сборке и тестированию находятся в [README.md](README.md).

Исходный код Plus: `plus/src/`. Единый русский словарь: `locales/ru.js`. Собранный userscript: `plus/backloggd-plus.user.js`; бандл расширения: `lib/plus-bundle.js`.
